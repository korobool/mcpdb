## Execution Log

### Step 1 (sql) — success (39ms)

```sql
SELECT
  T4.mc_make_name AS car_make,
  AVG(T1.total_cost) AS average_damage_cost
FROM ins_damages AS T1
INNER JOIN ins_opis AS T2
  ON T1.damage_id = T2.damage_id
INNER JOIN ins_cars AS T3
  ON T2.car_id = T3.car_id
INNER JOIN srv_mc_catalog_make AS T4
  ON T3.car_make = T4.mc_make
GROUP BY
  car_make
ORDER BY
  average_damage_cost DESC
LIMIT 5;
```
