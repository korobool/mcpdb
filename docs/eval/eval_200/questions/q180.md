# Q180: Which suppliers have the highest average expense line value? Show top 5 with at least 10 lines.

## Ground Truth

### SQL
```sql
SELECT supplier_name, AVG(value_vat) AS avg_value, COUNT(*) AS line_cnt FROM ins_mc_invexpenses WHERE supplier_name IS NOT NULL AND supplier_name != '' GROUP BY supplier_name HAVING line_cnt >= 10 ORDER BY avg_value DESC LIMIT 5
```
