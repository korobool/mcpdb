## Ground Truth

### SQL
```sql
WITH top5 AS (SELECT service_id FROM ins_invrepair GROUP BY service_id ORDER BY COUNT(*) DESC LIMIT 5) SELECT ir.service_id, AVG(DATEDIFF(ir.end_repair, ir.start_repair)) AS avg_days, COUNT(*) AS repairs FROM ins_invrepair ir INNER JOIN top5 t ON t.service_id=ir.service_id WHERE ir.start_repair IS NOT NULL AND ir.end_repair IS NOT NULL GROUP BY ir.service_id ORDER BY avg_days
```
