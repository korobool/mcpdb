# Q286: Show claim count by claim_type and whether an MC estimate exists.

## Ground Truth

### SQL
```sql
SELECT o.claim_type, CASE WHEN ic.opis_id IS NOT NULL THEN 'Has MC' ELSE 'No MC' END AS mc_status, COUNT(*) AS claims FROM ins_opis o LEFT JOIN (SELECT DISTINCT opis_id FROM ins_mc_invcalc WHERE type='mc') ic ON ic.opis_id=o.opis_id GROUP BY o.claim_type, mc_status ORDER BY o.claim_type, mc_status
```
