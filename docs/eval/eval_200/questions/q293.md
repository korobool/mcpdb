## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id), max_sev AS (SELECT opis_id, MAX(part_repair) AS max_severity FROM ins_opis_rows GROUP BY opis_id) SELECT ms.max_severity, AVG(mc.total_cost) AS avg_cost, COUNT(*) AS claims FROM latest_mc mc JOIN max_sev ms ON ms.opis_id=mc.opis_id GROUP BY ms.max_severity ORDER BY ms.max_severity
```

## Agent Execution

### Step 1 (SQL) — OK
```sql
WITH RepairSeverity AS (
    SELECT 
        opis_id,
        MAX(part_repair) AS max_repair_severity
    FROM 
        ins_opis_rows
    GROUP BY 
        opis_id
)
SELECT 
    rs.max_repair_severity,
    AVG(imc.total_cost) AS average_estimated_cost
FROM 
    RepairSeverity rs
JOIN 
    ins_mc_invcalc imc ON rs.opis_id = imc.opis_id
WHERE 
    imc.is_active = 1
GROUP BY 
    rs.max_repair_severity
ORDER BY 
    rs.max_repair_severity;
```
