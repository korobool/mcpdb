## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id) SELECT d.car_yeargroup, AVG(mc.total_cost) AS avg_cost, COUNT(*) AS claims FROM latest_mc mc JOIN ins_opis o ON o.opis_id=mc.opis_id JOIN ins_damages d ON d.damage_id=o.damage_id GROUP BY d.car_yeargroup ORDER BY d.car_yeargroup
```

## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  T1.car_yeargroup,
  AVG(T3.total_cost) AS average_estimated_cost
FROM ins_damages AS T1
INNER JOIN ins_opis AS T2
  ON T1.damage_id = T2.damage_id
INNER JOIN ins_mc_invcalc AS T3
  ON T2.opis_id = T3.opis_id
WHERE
  T3.is_active = 1
  AND T1.car_yeargroup IS NOT NULL
GROUP BY
  T1.car_yeargroup
ORDER BY
  T1.car_yeargroup;
```
