## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  T4.modelname_name AS car_model_name,
  COUNT(T1.opis_id) AS claim_frequency
FROM ins_opis AS T1
INNER JOIN ins_cars AS T2
  ON T1.car_id = T2.car_id
INNER JOIN srv_mc_horizon_model AS T3
  ON T2.car_make = T3.mc_make
  AND T2.car_model = T3.mc_model
INNER JOIN srv_mc_horizon_modelname AS T4
  ON T3.category_id = T4.category_id
  AND T3.brand_id = T4.brand_id
  AND T3.modelname_id = T4.modelname_id
GROUP BY
  car_model_name
ORDER BY
  claim_frequency DESC
LIMIT 5;
```
