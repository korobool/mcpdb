### Step 3 (SQL) — OK
```sql
SELECT
  T2.supplier_name,
  COUNT(DISTINCT T1.car_make_name) AS distinct_car_brands
FROM ins_invrepair AS T1
INNER JOIN ins_mc_invexpenses AS T2
  ON T1.service_id = T2.supplier_id
WHERE
  T2.supplier_name IS NOT NULL
  AND T2.supplier_name <> ''
GROUP BY
  T2.supplier_name
ORDER BY
  distinct_car_brands DESC
LIMIT 5;
```
