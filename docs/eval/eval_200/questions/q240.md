## Ground Truth

### SQL
```sql
SELECT o.claim_type, AVG(DATEDIFF(o.opis_date, d.damage_date)) AS avg_lag_days FROM ins_opis o JOIN ins_damages d ON d.damage_id=o.damage_id WHERE d.damage_date IS NOT NULL AND o.opis_date IS NOT NULL GROUP BY o.claim_type ORDER BY avg_lag_days
```
