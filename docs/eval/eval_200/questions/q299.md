## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id) SELECT CASE WHEN DATEDIFF(o.opis_date, d.damage_date) <= 7 THEN '0-7 days' WHEN DATEDIFF(o.opis_date, d.damage_date) <= 30 THEN '8-30 days' WHEN DATEDIFF(o.opis_date, d.damage_date) <= 90 THEN '31-90 days' ELSE '90+ days' END AS lag_bucket, AVG(mc.total_cost) AS avg_cost, COUNT(*) AS claims FROM latest_mc mc JOIN ins_opis o ON o.opis_id=mc.opis_id JOIN ins_damages d ON d.damage_id=o.damage_id WHERE d.damage_date IS NOT NULL AND o.opis_date IS NOT NULL GROUP BY lag_bucket ORDER BY MIN(DATEDIFF(o.opis_date, d.damage_date))
```

## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  CASE
    WHEN DATEDIFF(t1.damage_notice, t1.damage_date) BETWEEN 0 AND 7 THEN '0-7 days'
    WHEN DATEDIFF(t1.damage_notice, t1.damage_date) BETWEEN 8 AND 30 THEN '8-30 days'
    WHEN DATEDIFF(t1.damage_notice, t1.damage_date) BETWEEN 31 AND 90 THEN '31-90 days'
    WHEN DATEDIFF(t1.damage_notice, t1.damage_date) > 90 THEN '90+ days'
  END AS filing_lag_bucket,
  AVG(t3.total_cost) AS average_mc_estimated_cost
FROM ins_damages AS t1
JOIN ins_opis AS t2 ON t1.damage_id = t2.damage_id
JOIN ins_mc_invcalc AS t3 ON t2.opis_id = t3.opis_id
WHERE t1.damage_notice IS NOT NULL AND t1.damage_date IS NOT NULL AND DATEDIFF(t1.damage_notice, t1.damage_date) >= 0
GROUP BY filing_lag_bucket
ORDER BY MIN(DATEDIFF(t1.damage_notice, t1.damage_date));
```

### Key Findings

*   **Consistent Costs Outside the Spike:** Claims filed very quickly (0-7 days) or after a longer delay (31+ days) have remarkably similar and lower average costs, all falling within a narrow range of approximately $940 to $995.
