## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id) SELECT CASE WHEN total_cost < 1000 THEN '0-1000' WHEN total_cost < 3000 THEN '1000-3000' WHEN total_cost < 5000 THEN '3000-5000' WHEN total_cost < 10000 THEN '5000-10000' ELSE '10000+' END AS cost_range, COUNT(*) AS claims FROM latest_mc GROUP BY cost_range ORDER BY MIN(total_cost)
```

