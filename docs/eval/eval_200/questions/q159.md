## Ground Truth

### SQL
```sql
SELECT b.brand_name, AVG(CASE WHEN r.part_paint=1 THEN 1.0 ELSE 0.0 END) AS paint_share, COUNT(*) AS damage_lines FROM ins_opis_rows r JOIN ins_opis o ON o.opis_id=r.opis_id JOIN ins_cars c ON c.car_id=o.car_id JOIN srv_mc_horizon_brand b ON c.car_mc_brand=b.brand_id GROUP BY b.brand_name ORDER BY paint_share DESC
```

## Agent Execution

### Step 1 (SQL) — OK

```sql
  T4.brand_name,
  AVG(T1.part_paint) AS paint_frequency
FROM ins_opis_rows AS T1
JOIN ins_opis AS T2
  ON T1.opis_id = T2.opis_id

  ON T2.car_id = T3.car_id

  ON T3.car_mc_brand = T4.brand_id

  T4.brand_name
```
