# Q136: What is the average mount cost share from latest MC estimates?

**Category:** Cost — MC estimate cost severity, structure, and percentiles  
**Type:** numeric  
**Result:** PASS (score=1)  
**Mode:** simple

## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id) SELECT ROUND(100*AVG(mounts_cost/NULLIF(total_cost,0)),2) AS avg_mount_share_pct FROM latest_mc WHERE total_cost > 0
```

### Answer
```
13.65
```
