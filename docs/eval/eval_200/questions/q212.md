## Ground Truth

### SQL
```sql
WITH latest AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, type, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc GROUP BY opis_id, type) lt ON lt.opis_id=ic.opis_id AND lt.type=ic.type AND lt.max_id=ic.invcalc_id) SELECT AVG(CASE WHEN type='mc' THEN total_cost END) AS avg_mc, AVG(CASE WHEN type='n24' THEN total_cost END) AS avg_n24 FROM latest
```
