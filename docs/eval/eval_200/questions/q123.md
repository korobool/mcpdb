## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id) SELECT ROUND(100*AVG(newparts_cost/NULLIF(total_cost,0)),2) AS pct_parts, ROUND(100*AVG(repairs_cost/NULLIF(total_cost,0)),2) AS pct_repairs, ROUND(100*AVG(mounts_cost/NULLIF(total_cost,0)),2) AS pct_mounts, ROUND(100*AVG(paints_cost/NULLIF(total_cost,0)),2) AS pct_paints, ROUND(100*AVG(other_cost/NULLIF(total_cost,0)),2) AS pct_other FROM latest_mc WHERE total_cost > 0
```

### Result Rows (sample)
```
[(21.02, 8.96, 13.65, 53.02, 0.0)]
```

### Patterns & Insights

- Uses **latest MC estimate** pattern (MAX invcalc_id per opis_id, type='mc')
- Uses **NULLIF** to prevent division by zero
