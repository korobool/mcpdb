# Q157: What are the top 5 parts by major repair count (part_repair=3)?

**Category:** Parts — Damage lines, part resolution, repair severity  
**Type:** top_n  
**Result:** PASS (score=1)

## Ground Truth

### SQL
```sql
SELECT COALESCE(pi.part_name, pf.part_name) AS part_name, COUNT(*) AS cnt FROM ins_opis_rows r LEFT JOIN ins_partsindex pi ON r.part_id=pi.part_id AND r.part_id < 10000000 LEFT JOIN ins_partsfree pf ON r.part_id=pf.part_id AND r.part_id >= 20000000 WHERE r.part_repair=3 GROUP BY part_name ORDER BY cnt DESC LIMIT 5
```
