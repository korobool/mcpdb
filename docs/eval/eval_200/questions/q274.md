## Ground Truth

### SQL
```sql
SELECT d.damage_place, AVG(DATEDIFF(ir.end_repair, ir.start_repair)) AS avg_days, COUNT(*) AS repairs FROM ins_invrepair ir JOIN ins_opis o ON o.opis_id=ir.opis_id JOIN ins_damages d ON d.damage_id=o.damage_id WHERE d.damage_place IS NOT NULL AND d.damage_place != '' AND ir.start_repair IS NOT NULL AND ir.end_repair IS NOT NULL GROUP BY d.damage_place HAVING repairs >= 3 ORDER BY repairs DESC LIMIT 5
```
