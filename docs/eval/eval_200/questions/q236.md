# Q236: What is the average number of days between the damage event and the first generated document?

SELECT AVG(DATEDIFF(g.first_gen, d.damage_date)) AS avg_days FROM ins_damages d JOIN ins_opis o ON o.damage_id=d.damage_id JOIN (SELECT opis_id, MIN(gen_date) AS first_gen FROM ins_gendocs GROUP BY opis_id) g ON g.opis_id=o.opis_id WHERE d.damage_date IS NOT NULL

## Agent Execution

### Step 1 (SQL) — OK
```sql
WITH FirstDocDate AS (
    SELECT
        o.damage_id,
        MIN(g.gen_date) AS first_doc_date
    FROM ins_opis AS o
    JOIN ins_gendocs AS g ON o.opis_id = g.opis_id
    GROUP BY o.damage_id
)
SELECT
    AVG(DATEDIFF(fdd.first_doc_date, d.damage_date)) AS average_days_to_first_document
FROM ins_damages AS d
JOIN FirstDocDate AS fdd ON d.damage_id = fdd.damage_id
WHERE d.damage_date IS NOT NULL AND fdd.first_doc_date IS NOT NULL;
```
