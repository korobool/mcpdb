## Ground Truth

### SQL
```sql
SELECT d.damage_place_country, AVG(DATEDIFF(o.opis_date, d.damage_date)) AS avg_lag FROM ins_opis o JOIN ins_damages d ON d.damage_id=o.damage_id WHERE d.damage_place_country IS NOT NULL AND d.damage_place_country != '' AND d.damage_date IS NOT NULL AND o.opis_date IS NOT NULL GROUP BY d.damage_place_country ORDER BY avg_lag
```
