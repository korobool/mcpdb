### SQL
```sql
SELECT YEAR(o.opis_date) AS yr, SUM(e.value_vat) AS total_value FROM ins_mc_invexpenses e JOIN ins_mc_invcalc ic ON e.doc_id=ic.invcalc_id JOIN ins_opis o ON o.opis_id=ic.opis_id WHERE o.opis_date IS NOT NULL GROUP BY yr ORDER BY yr
```

## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  YEAR(t1.opis_date) AS year_of_opis,
  SUM(t3.value_vat) AS total_expense_value
FROM ins_opis AS t1
INNER JOIN ins_mc_invcalc AS t2
  ON t1.opis_id = t2.opis_id
INNER JOIN ins_mc_invexpenses AS t3
  ON t2.invcalc_id = t3.doc_id
WHERE
  t1.opis_date IS NOT NULL
GROUP BY
  year_of_opis
ORDER BY
  year_of_opis;
```
