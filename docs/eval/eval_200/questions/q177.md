# Q177: What is the average final_price by expense type (joined with inv_exptypes)?

## Ground Truth

### SQL
```sql
SELECT t.et_name, AVG(e.final_price) AS avg_price FROM ins_mc_invexpenses e LEFT JOIN inv_exptypes t ON t.exptype_id=e.expense_type WHERE e.final_price > 0 GROUP BY t.et_name ORDER BY avg_price DESC
```
