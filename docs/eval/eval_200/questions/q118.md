## Agent Execution

### Step 1 (SQL) — OK
```sql
WITH ClaimsPerCar AS (
  SELECT
    car_id,
    COUNT(opis_id) AS claim_count
  FROM ins_opis
  GROUP BY
    car_id
)
SELECT
  CASE
    WHEN claim_count = 1 THEN '1 claim'
    WHEN claim_count = 2 THEN '2 claims'
    ELSE '3 or more claims'
  END AS claim_category,
  COUNT(car_id) AS number_of_cars
FROM ClaimsPerCar
GROUP BY
  claim_category
ORDER BY
  claim_category;
```
