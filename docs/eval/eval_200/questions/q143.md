# Q143: What is the 90th percentile (P90) of MC estimated total cost?

## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id), ranked AS (SELECT total_cost, ROW_NUMBER() OVER (ORDER BY total_cost) AS rn, COUNT(*) OVER() AS cnt FROM latest_mc WHERE total_cost > 0) SELECT total_cost AS p90_cost FROM ranked WHERE rn = CEIL(0.9 * cnt) LIMIT 1
```
