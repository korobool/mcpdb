## Agent Execution

### Step 1 (SQL) — OK
```sql
WITH DamageLines AS (
    SELECT
        opis_id,
        COUNT(opis_rowid) AS num_damage_lines
    FROM ins_opis_rows
    GROUP BY opis_id
)
SELECT
    d.car_yeargroup,
    AVG(dl.num_damage_lines) AS average_damage_lines
FROM DamageLines dl
JOIN ins_opis o ON dl.opis_id = o.opis_id
JOIN ins_damages d ON o.damage_id = d.damage_id
GROUP BY d.car_yeargroup
ORDER BY d.car_yeargroup;
```
