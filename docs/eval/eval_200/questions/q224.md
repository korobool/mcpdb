## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  YEAR(T3.opis_date) AS creation_year,
  COUNT(DISTINCT T3.opis_id) AS number_of_n24_estimates
FROM ins_mc_invexpenses AS T1
JOIN ins_mc_invcalc AS T2
  ON T1.doc_id = T2.invcalc_id
JOIN ins_opis AS T3
  ON T2.opis_id = T3.opis_id
WHERE
  T1.expense_name LIKE '%N24%'
GROUP BY
  creation_year
ORDER BY
  creation_year;
```
