## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  T3.brand_name,
  COUNT(DISTINCT T1.opis_id) AS claim_count,
  AVG(T4.total_cost) AS average_cost
FROM ins_opis AS T1
JOIN ins_cars AS T2
  ON T1.car_id = T2.car_id
JOIN srv_mc_horizon_brand AS T3
  ON T2.car_mc_brand = T3.brand_id
JOIN ins_mc_invcalc AS T4
  ON T1.opis_id = T4.opis_id
WHERE
  T4.is_active = 1
GROUP BY
  T3.brand_name
ORDER BY
  claim_count DESC;
```
