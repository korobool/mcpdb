# Q163: Which parts have the highest ratio of major repairs (part_repair=3) to total occurrences? Show top 5 with at least 5 occurrences.

**Category:** Parts — Damage lines, part resolution, repair severity  
**Type:** top_n  
**Result:** PASS (score=1)  
**Mode:** simple  
**Time:** 39.62s  

---

## Ground Truth

### SQL
```sql
SELECT COALESCE(pi.part_name, pf.part_name) AS part_name, SUM(CASE WHEN r.part_repair=3 THEN 1 ELSE 0 END) / COUNT(*) AS major_ratio, COUNT(*) AS total FROM ins_opis_rows r LEFT JOIN ins_partsindex pi ON r.part_id=pi.part_id AND r.part_id < 10000000 LEFT JOIN ins_partsfree pf ON r.part_id=pf.part_id AND r.part_id >= 20000000 GROUP BY part_name HAVING total >= 5 ORDER BY major_ratio DESC LIMIT 5
```
