## Ground Truth

### SQL
```sql
SELECT CASE WHEN d <= 7 THEN '0-7' WHEN d <= 14 THEN '8-14' WHEN d <= 30 THEN '15-30' ELSE '31+' END AS bucket, COUNT(*) AS cnt FROM (SELECT DATEDIFF(end_repair, start_repair) AS d FROM ins_invrepair WHERE start_repair IS NOT NULL AND end_repair IS NOT NULL) t GROUP BY bucket ORDER BY MIN(d)
```


## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT 
    CASE 
        WHEN DATEDIFF(end_repair, start_repair) BETWEEN 0 AND 7 THEN '0-7 days'
        WHEN DATEDIFF(end_repair, start_repair) BETWEEN 8 AND 14 THEN '8-14 days'
        WHEN DATEDIFF(end_repair, start_repair) BETWEEN 15 AND 30 THEN '15-30 days'
        ELSE '31+ days'
    END AS duration_bucket,
    COUNT(*) AS number_of_repairs
FROM ins_invrepair
WHERE start_repair IS NOT NULL AND end_repair IS NOT NULL
GROUP BY duration_bucket
ORDER BY MIN(DATEDIFF(end_repair, start_repair));
```
