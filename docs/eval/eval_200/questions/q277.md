# Q277: Which damage location has the highest average MC estimated cost? Show top 5 with at least 3 claims.

## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id) SELECT d.damage_place, AVG(mc.total_cost) AS avg_cost, COUNT(*) AS claims FROM latest_mc mc JOIN ins_opis o ON o.opis_id=mc.opis_id JOIN ins_damages d ON d.damage_id=o.damage_id WHERE d.damage_place IS NOT NULL AND d.damage_place != '' GROUP BY d.damage_place HAVING claims >= 3 ORDER BY avg_cost DESC LIMIT 5
```
