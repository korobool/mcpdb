### Step 1 (SQL) — OK
```sql
SELECT
  T4.mc_make_name AS car_brand,
  COUNT(T1.damage_id) AS number_of_claims
FROM ins_damages AS T1
INNER JOIN ins_opis AS T2
  ON T1.damage_id = T2.damage_id
INNER JOIN ins_cars AS T3
  ON T2.car_id = T3.car_id
INNER JOIN srv_mc_catalog_make AS T4
  ON T3.car_make = T4.mc_make
WHERE
  T1.damage_place LIKE '%Sofia%' OR T1.damage_place LIKE '%София%'
GROUP BY
  car_brand
ORDER BY
  number_of_claims DESC
LIMIT 5;
```
