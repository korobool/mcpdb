## Ground Truth

### SQL
```sql
WITH latest_mc AS (SELECT ic.* FROM ins_mc_invcalc ic INNER JOIN (SELECT opis_id, MAX(invcalc_id) AS max_id FROM ins_mc_invcalc WHERE type='mc' GROUP BY opis_id) lm ON lm.opis_id=ic.opis_id AND lm.max_id=ic.invcalc_id), dmg_lines AS (SELECT opis_id, COUNT(*) AS damage_lines FROM ins_opis_rows GROUP BY opis_id) SELECT mc.opis_id, l.damage_lines, (mc.repairs_hours + mc.mounts_hours + mc.paints_hours) AS total_hours, ROUND((mc.repairs_hours + mc.mounts_hours + mc.paints_hours) / NULLIF(l.damage_lines, 0), 2) AS hours_per_line FROM latest_mc mc JOIN dmg_lines l ON l.opis_id=mc.opis_id WHERE l.damage_lines >= 1 ORDER BY hours_per_line DESC LIMIT 10
```

## Agent Execution

### Step 1 (SQL) — OK
```sql
SELECT
  T1.damage_id,
  T1.damage_number,
  AVG(T1.repairs_hours + T1.mounts_hours) AS total_labor_hours,
  COUNT(T3.opis_rowid) AS num_damage_lines,
  AVG(T1.repairs_hours + T1.mounts_hours) / COUNT(T3.opis_rowid) AS avg_hours_per_line
FROM ins_damages AS T1
JOIN ins_opis AS T2
  ON T1.damage_id = T2.damage_id
JOIN ins_opis_rows AS T3
  ON T2.opis_id = T3.opis_id
GROUP BY
  T1.damage_id,
  T1.damage_number
HAVING
  COUNT(T3.opis_rowid) > 0
ORDER BY
  avg_hours_per_line DESC
LIMIT 10;
```
